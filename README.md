# California House Price Prediction (机器学习)

## 项目目标
利用 Scikit-learn 对加州房价数据集进行建模，预测房屋价格，并对比不同机器学习模型的表现。

## 使用工具
*   Python (Pandas, NumPy, Matplotlib, Seaborn)
*   Scikit-learn (数据划分、标准化、线性回归、随机森林回归)

## 分析过程
1.  **数据探索与清洗**：加载 20,640 条样本，探索房价分布与特征相关性。
2.  **数据预处理**：进行 80/20 训练集测试集划分，并使用 `StandardScaler` 对特征进行标准化。
3.  **模型训练**：分别构建线性回归和随机森林回归模型。
4.  **模型评估**：使用 MSE、RMSE 和 R² 进行评估。

## 核心结论
*   模型在测试集上达到了 **R² = 0.80**，说明模型能解释 80% 的房价波动。
*   通过热力图发现，收入中位数（MedInc）是影响房价的最强特征（相关系数 0.69）。
*   对比发现，线性回归与随机森林在该数据集上表现几乎一致，考虑到计算开销和可解释性，线性回归是更优的生产环境选择。
